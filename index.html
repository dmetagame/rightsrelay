The decision

The model can explain.
The gate decides.

A deterministic function compares the requested release with the authorization recalled from Sibyl. If memory is absent or the scope does not match, no packet exists to ship.

  1. 01

    Recall one authority

    A fresh process reads the single mutable UseAuthorization entity. No transcript is passed between actors.

    Sibyl WARM
  2. 02

    Compare exact scope

    Channel, paid-media use, territory, identity, and dates are evaluated by pure policy—not an LLM.

    Mismatch
  3. 03

    Refuse the artifact

    A blocked attempt returns concrete reasons and the export boundary writes nothing.

    Packet: none
  4. 04

    Acquire, update, retry

    A settled x402 grant expands the same entity. The identical request now clears and produces its packet.

    Cleared
